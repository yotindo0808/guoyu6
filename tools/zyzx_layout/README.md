# 字音字形學習單　排版程式（定案版）

這是固定的排版方式。整理好一課的資料（JSON）之後，執行程式就會排出同樣版面的學習單，不需要另外設計。

## 輸出
| 檔案 | 頁數 |
|---|---|
| 字音字形學習單（上課用）＋教師解答版 | B5 直式 4 頁（2 張雙面） |
| 字音字形綜合練習＋教師解答版 | B5 直式 2 頁（1 張雙面） |

## 執行
1. 把芫荽（`Iansui-Regular.ttf`）和ㄅ注音芫荽（`BpmfIansui-Regular.ttf`）放進 `fonts/` 資料夾。
2. 參考 `examples/五上_第七課.json` 的格式，建立這一課的 JSON。
3. 執行 `bash run.sh 課次.json [輸出資料夾]`。

需要的環境：Python 3（fonttools、Pillow）、Node.js（docx 套件）。要轉出 PDF 的話，另外需要 LibreOffice。

## JSON 重點
- `bookLabel`、`lessonTitle`、`fileLabel`：頁首與檔名，依年級、課次填寫。
- `shapeRows`（部件帶字）：一個題組最多 4 個字；兩字的題組可以兩組並排。用 `"PAGEBREAK"` 換頁。第 1 頁放 2 列，其他頁每頁放 3 列。`model: true` 代表本課生字，會以灰底示範。
- `poly`（多音字）：語詞中用 `[ ]` 標出要學生判斷讀音的字，並附上正確讀音。
- `expand`（部件擴充）：參考答案只放「部件＋部首」直接組成的字。
- `polyQ`（讀音判斷）：`[ ]` 標出要判斷讀音的字。`pick`（選字填空）：`__` 是填空的位置，一面最多 12 題，每句 12 字以內。
- 句子中的多音字讀錯時，在該字後面加 `{n}`，指定第 n 個讀音，例如 `弟弟{2}`。執行時會列出所有多音字和它會印出的讀音，方便逐一檢查。

## 版面規格（已定案）
- B5 直式，字型使用芫荽，注音使用ㄅ注音芫荽，字級 16 pt 以上。
- 語詞與句子都是直書，由右到左排列；字旁注音取自注音字型，聲調位置正確。
- 共同部件用紅色粗體；國字田字格 1.5 × 1.5 公分；造詞以兩色底色區分詞組。
- 多音字和讀音判斷都是在粗體字右側的方格填注音；選字填空的選項標在每組上方。
